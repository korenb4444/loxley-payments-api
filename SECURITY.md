# Security

Please report suspected vulnerabilities to security@loxleypayments.com. Do not open public issues.

- Dependencies are kept up to date and critical or high severity vulnerabilities are patched within 30 days, in line with the Loxley Vulnerability & Patch Management Standard (SEC-STD-004).
- Secrets must never be committed; GitHub secret scanning with push protection is enabled for the organisation.
- Changes under `src/auth/` require review from the Security team.
- Repository access, including contractors, is reviewed quarterly; see `docs/third-party-access.md`.
